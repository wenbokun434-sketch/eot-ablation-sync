# EOT 阈值与 Loss 优化协议 v1

协议 ID：`eot_threshold_loss_v1`。制定日期：2026-09-10。适用任务：根目录 `优化TODO.md` 的 O02–O15。

机器可读规则：`outputs/optimization/v1/protocol/protocol_v1.json`。本文件与该 JSON 在 O02 验收时一起锁定哈希。后续实现必须遵守两者；不一致时停止对应任务并记录问题，不能自行挑选有利解释。

## 1. 目标、研究性质与基线

优化正类 Recall 与总体 Accuracy，期望两项同时提升。正类 Precision、F1、AP（PR-AUC）、Balanced Accuracy、MCC、Brier Score 与早期检测指标完整保留。

原实验已报告 Accuracy=93.95%、Recall=54.90%，但本次方案制定前已经查看过原测试结果和事后阈值对照。因此本协议是“新优化运行前锁定的事后补充实验”，不是从未查看过测试数据的确认性研究。单独修改阈值的旧对照只作动机，不用于新的逐折选择。

固定四个报告对象：

| 对象 | 定义 | 作用 |
| --- | --- | --- |
| R0 | 原冻结正式模型、原划分训练流程、原早期阈值同时用于最终分类 | 历史比较；其预测和测试指标不进入优化选择接口 |
| R1 | 新协议训练的 A 模型；在合法选择集上按原 F-latency 选早期阈值，并同时用于最终分类 | 同新协议、原 loss 与原决策逻辑的参考；提供阈值 Accuracy 下限 |
| R2 | 与 R1 完全相同的 A 模型概率；最终分类用受约束的新阈值，早期阈值不变 | 只改变最终决策的对照；也是新 loss 必须比较的基线 |
| OPT | 各外层独立选择的 loss、新最终阈值和预定校准回退流程 | 主要评价对象；不同外层允许选中不同候选，报告的是选择流程 |

主要比较 OPT 对 R2，辅助比较 R2 对 R1、OPT 对 R1，以及 OPT 对历史 R0。新流程改变了模型选择和最终 epoch 确定方式，不能把 OPT 对 R0 的全部差异归因于 loss。

## 2. 固定范围与数据角色

保留原外层五折测试成员及原 train/validation 成员。**不合并原 train 与 validation。** 对每个外层 `f=0..4` 定义：

| 符号 | 来源 | 数量概况 | 允许用途 |
| --- | --- | --- | --- |
| S | `data/splits/fold_f.json` 的 `train_user_ids` | 636 或 637 人，71 或 72 名正类 | 内层 loss 筛选、训练统计、epoch 确定及最终梯度训练 |
| C | 同文件的 `validation_user_ids` | 91 人，10 名正类 | 仅用于 O14 最终实际模型的阈值校准及预定回退；不参与 loss 搜索、训练或 epoch 选择 |
| T | 同文件的 `test_user_ids` | 181 或 182 人 | 全部外层模型与双阈值锁定后的最终评价 |

C 原来用于旧模型的早停；本轮所有模型必须从头训练，不能加载旧 checkpoint 后宣称 C 独立。新模型在 C 上不会更新权重或选择 epoch。此前人类/分析过程已经看过的结果不能撤销，因此仍需保留事后研究声明。

各外层自己的 S/C/T 必须互斥；不同外层的角色会交叉，这是交叉验证的结构，不能跨外层汇集标签为某一外层选参。每个外层只读本外层获准的数据角色。

原始数据、清洗文本、冻结 encoder revision、向量顺序、最早 256 帖、256 tokens、ODE/GRU/Transformer、mask、时间变换公式保持不变。优化期间无需重新打开原始帖子做特征修改。

## 3. 内层划分、早停及统计拟合

O04 才实际创建划分；O02 只锁规则。

1. S 用户按 ID 排序，使用 `StratifiedKFold(n_splits=3, shuffle=True, random_state=10042+f)` 生成内层留出集 H_j，`j=0..2`。
2. 对 `S \ H_j` 使用分层 `train_test_split(test_size=0.125, random_state=20042+10*f+j)`，得到梯度训练集 G_j 和早停集 E_j。使用实际样本数按 scikit-learn 规则取整，不手工挪动某类用户。
3. G_j、E_j、H_j、C、T 在当前外层/内层运行中互斥；三个 H_j 的并集恰好为 S。所有 loss 与模型种子共享这些成员。
4. 时间 q99、`log1p` 缩放、类别人数和 `pos_weight` 只从 G_j 拟合。E_j/H_j 复用 G_j 的统计。即使已有外层统计文件，也不得用于含内层留出用户的拟合。
5. 只用 E_j 的完整序列 AP 早停：最多 50 epochs、patience=8、严格提升超过 `1e-12` 才更新 best；同分保留较早 epoch。H_j 不参与梯度或早停。
6. best checkpoint 锁定后生成 H_j 的完整及前缀概率，才可在 H_j 上选择阈值和计算内层选择分数。

H_j 的模型预测未使用该用户训练，但阈值及候选选择会拟合 H_j 标签，故内层选择成绩仍可能乐观；它不是独立最终成绩。类别缺失或无法合法分层时失败，不改变比例补救后继续冒充原协议。

## 4. Loss、训练常量与数值要求

主比较公式：`L = L_final + λ × L_prefix`，正类权重 `w_pos=α×N_negative(G)/N_positive(G)`。A–D 固定为：

| ID | 最终 loss | α | λ |
| --- | --- | --- | --- |
| A | 加权 BCE | 1.0 | 0.50 |
| B | 加权 BCE | 1.0 | 0.25 |
| C | 加权 BCE | 0.5 | 0.50 |
| D | 加权 BCE | 1.5 | 0.50 |

所有前缀继续使用相同 w_pos 的加权 BCE，检查点 `[1,2,4,8,16,32,64,128,256]`，先按每用户有效检查点平均，再对用户平均。A 必须与旧 `EOTLoss` 在相同输入上 loss/梯度一致；不增加按类别权重和再次归一化等隐含变化。

保持 AdamW、learning_rate=0.0008、weight_decay=0.01、batch_users=128、mixed_precision=false、gradient_clip_norm=1.0。模型初始化使用训练种子；每个 epoch 的打乱种子为 `training_seed+epoch`，沿用原逻辑。三个训练种子为 42、43、44。基线和候选必须在相同依赖环境运行并记录环境；不默认把旧环境记录当作当前实测环境。

有条件 Focal 仅替换最终分支。令 `p=sigmoid(z)`：

`L_focal = w_pos*y*(1-p)^γ*softplus(-z) + (1-y)*p^γ*softplus(z)`。

不再另加一个 Focal 类别 alpha；`α` 始终只表示 pos_weight 倍率。γ=0 时必须还原相同权重 BCE。用稳定 logits 计算，避免对零概率直接取 log。λ=0 时前缀 loss 不贡献优化梯度。

## 5. 双阈值、Accuracy 约束与确定性并列规则

选择集 Q 只可能是某个 H_j 或最终 C，不可能是 T。读取原 `metrics.DEFAULT_THRESHOLD_GRID` 的 201 个候选（0–1，步长 0.005），正类判定始终为 `p >= t`。

**先集成后选阈值**：对同一内层折或最终模型的三个种子，先在相同用户/前缀位置对概率取算术均值，再选择集成阈值。O10 仅种子 42，相当于单种子预测；O11 必须对三种子集成重新选择，不能沿用 O10 阈值。

在同一 Q 上先计算 A 的早期阈值 `tau_A_early`：复用原 F-latency 选择器、连续两次越阈及并列规则（F-latency、early F1、speed 更高，ERDE50 更低，threshold 更高）。A 最后有效概率与该阈值比较，形成 R1。记录 R1 的正确人数 `K_ref`。

每个候选（包括 A）的最终阈值选择：

1. 对所有 t 计算该候选在 Q 上的 TP、TN、FP、FN。
2. 保留 `TP+TN >= K_ref` 的 t。用户集合相同，因此使用整数比较，不对 Accuracy 四舍五入。
3. 在可行 t 中按 `(TP 更高, TP+TN 更高, Precision 更高, t 更高)` 排序取第一。无预测正类时 Precision 按 0 定义。
4. 若无可行 t，保存 `threshold_final=null`、`status=infeasible`，该候选不能晋级；不得借用 A 预测填成候选自己的结果。
5. A 至少可使用 `tau_A_early`，因此必然可行，形成 R2。若 R2 与 R1 决策相同，记录 unchanged。

每个候选的 `threshold_early` 仍由它自己的 Q 前缀概率按原规则选择，与 `threshold_final` 分开保存。新最终阈值不用于反算早期告警。所有阈值的 manifest 记录 Q 用户集合哈希、标签角色、模型/集成哈希、网格、目标和并列顺序。

## 6. O10 初筛与 O11 稳定性规则

所有选择在各外层独立执行。

**O10**：A–D 在三个内层折各训练种子 42。针对每个 H_j 分别执行第 5 节，再合并三个 H_j 的决策计数（每人一次）。B/C/D 只有同时满足以下条件才晋级：

- 三个 H_j 均存在可行最终阈值。
- 合并正确人数不少于 R2，合并 TP 严格多于 R2。
- 至少两个 H_j 上，正确人数和 TP 均不低于 R2。

晋级全部满足条件的 B/C/D，最多三组；A 必须保留。没有其他晋级组时 O11 仍补齐 A 的种子，供预定 Focal 分支作参考。不得依据其他外层结果挽救本外层未晋级的组。

**O11**：仅对 A 和晋级组补齐 43、44，并对三种子集成重选双阈值。某候选称为“稳定候选”，必须满足：

- 三种子集成相对三种子 R2 再次满足 O10 的三个条件。
- 各种子分别以其自己的 R1/R2 和阈值形成内层合并指标；至少两个种子上候选正确人数及 TP 均不低于同种子 R2。

稳定候选排序：合并 Recall、更高的合并 Accuracy、更高的三个 H_j AP 等权平均值，最后取固定 ID 顺序 `B,C,D,E,F1,F2` 较前者。人数条件精确比较；浮点同分容差 `1e-12`。不用最高测试成绩，也不挑一个最好种子。

## 7. O12 条件实验与搜索上限

各外层按下面互斥分支执行，未触发也需记录原因。

| 分支 | 触发条件 | 固定新增设置 |
| --- | --- | --- |
| E：组合 | O11 后 B 稳定，且 C/D 至少一组稳定 | λ=0.25，α 取按第 6 节排序较好的稳定 C/D；最多一组 |
| F1 | O11 后无稳定 B/C/D | 最终加权 Focal γ=1，α=1，λ=0.5，前缀仍 BCE |
| F2 | F1 稳定，且其三内层 AP 等权均值不低于 R2（容差 1e-12） | 与 F1 相同但 γ=2 |
| 跳过 | 有稳定 BCE 但不满足 E，或相应触发条件失败 | 不增加实验 |

E 与 Focal 路径在同一外层不可同时运行。E 失败不改走 F1。新增组直接完成三个内层、三个种子，并按同一稳定性标准相对 R2 比较；O13 只在所有已通过稳定性标准的组中按固定顺序选一组。无稳定组则用 A/R2。

每外层最多 A–D 加两个可选组，共六种配置；五外层最多 270 次唯一内层训练，最终 A/候选最多 30 次，共 300 次（不含冒烟）。阶段间相同 fold/candidate/seed 的已完成运行复用，不重复计数。此为上限，不是承诺必须运行全部；不允许中途扩大网格。

## 8. O13 锁定与 O14 最终重训、校准

O13 只能读取 S 内层产物，为每个外层锁定 A 和一个稳定候选（或仅 A）、配置、三种子及最终训练轮数。对同一 candidate/seed，最终 epoch 取三个内层最佳 epoch 的整数中位数，范围 1–50。不得根据 C 或 T 改 epoch。

O14 为每个已锁 candidate/seed 从头初始化，在完整 S 上训练指定轮数；时间统计和正类权重只拟合 S。最后一轮模型就是最终模型，不用 C 早停，也不继承内层 checkpoint。A 按完全相同方式重训，形成同协议参考。

然后用这些实际最终模型对 C 推理，先平均种子概率，在 C 上重新生成 R1/R2、候选双阈值。**不迁移任何 H_j 阈值，也不在校准后重训。** 本版本不额外拟合 sigmoid/isotonic 概率校准器；“校准”在此指阈值确定。

锁定的最终回退规则：候选仅在 C 上满足阈值可行、正确人数不少于 C 上 R2、TP 严格多于 C 上 R2 时用于 OPT；否则 OPT 使用 A/R2。只允许回退基线，不试次优候选、不改参数、不补训练。被回退候选的 C 成绩仍保留，不能伪装为未运行。

这会使 OPT 在 C 上偏乐观，且 C 只有 10 名正类，门槛较粗。内层验证改善了 loss 搜索和稳定性检查，但没有消除最终小校准集的不确定性；不得宣称已经解决这一局限。

O13 锁定的是候选、epoch 和校准/回退规则；O14 校准后另存实际 checkpoint 哈希、双阈值、参考计数、回退结果与最终部署候选的第二份锁。**所有五折的第二份锁均完成后，才允许读取任何新候选的外层测试成绩。**

| 步骤 | 可用标签 | 不可用于选择的标签/成绩 |
| --- | --- | --- |
| 成员/类别计数审计 | 既有 split 的人数和角色元数据 | 不得借审计名义重算测试阈值 |
| 时间统计、pos_weight、梯度更新 | G_j（最终训练为 S） | E_j、H_j、C、T |
| 内层 early stopping | E_j | H_j、C、T |

强制检查：测试标签置换不改变协议、候选、epoch 或阈值；C 标签置换不能改变 O13 锁，仅可能影响预定的 O14 阈值/回退；H_j/E_j 改动不能改变 G_j 的归一化或类别权重。每个预测用户、每个 fit 统计量都记录成员哈希和角色。

共享无标签的冻结逐帖 embedding 是允许的；有标签的训练统计、模型选择与阈值选择必须按角色隔离。审计 helper 只哈希文件和检查既有成员/人数，不进行阈值搜索或新训练。

## 10. 最终评价与成功标准

五折测试用户合并为 909 人，每人一次。同折三种子先平均概率；R1/R2 共用 A 概率，仅决策不同。OPT 使用该外层锁定候选或回退 A。主要测试对象为 R1/R2/OPT，已淘汰候选不再逐个跑测试以寻找意外赢家。

报告各对象的 TP/TN/FP/FN、Accuracy、Recall、Precision、F1、AP、ROC-AUC、Balanced Accuracy、MCC、Brier Score，以及保持原定义的早期指标。另保存各折、各种子的描述性结果和各折最终选择/回退表，不按测试成绩挑种子。

“主要点估计双提升”要求 OPT 相对同新协议 R2 的 OOF Recall 和 Accuracy 均严格增加；另独立判断是否超过历史 R0 的两项指标。只一项改善叫取舍变化；Accuracy 持平、Recall 增加叫召回改善且准确率持平，不叫两项都提高。

对同一 OOF 用户配对 bootstrap 2,000 次、seed=42，两组每次使用相同用户索引，报告指标差值的 percentile 95% 区间。若出现单一类别重采样，跳过该次并报告各指标有效次数，不无限补抽。双终点的支持性判断要求两项差值的单侧 97.5% 下界（2.5% 分位数）均高于零，按两个主终点作 Bonferroni 控制；仍不把近似 bootstrap 结果称为精确检验。

这些区间以已训练模型、内层选择和阈值为条件，不包含重训/重新选择不确定性。其他比较均作描述，不扩展确认性显著性声明。最终独立确认仍需新的保留数据或新的预先约定评估；同一数据上的重复优化不能消除先前测试暴露。
