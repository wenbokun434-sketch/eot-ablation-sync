# 实验结果分析：时间间隔是否能提高准确率

本分析基于配置哈希 `91f378a1d396e71f75f41b2b24e60808e80b92c1146cc7eedccb05ec7ec825cc` 的五折、每折三个种子集成结果。这里的“时间间隔”指同一用户相邻有效帖子的实际发帖间隔，不是训练耗时、帖子数量或序列位置。

## 当前结果能说明什么

**目前可以确认包含时间间隔的 EOT 模型具有一定的分类能力，但尚不能确认引入时间间隔本身提高了准确率，也不能量化其独立增益。** 当前正式实验只有完整模型，没有相同数据划分和训练条件下的无时间间隔对照。

完整序列 OOF 预测共覆盖 909 名用户，其中正类 102 名、负类 807 名。按各折验证集锁定的阈值分类，得到 TP=56、TN=798、FP=9、FN=46。

| 指标 | 当前完整模型结果 | 解读 |
| --- | --- | --- |
| Accuracy（总体准确率） | 93.95%（854/909） | 所有用户中预测正确的比例 |
| Balanced Accuracy（平衡准确率） | 76.89% | 正、负两类召回率的平均值 |
| Precision（正类精确率） | 86.15% | 被判为正类的用户中，实际正类的比例 |
| Recall（正类召回率） | 54.90% | 实际正类用户中被识别的比例 |
| F1 | 0.6707 | 正类精确率与召回率的综合指标 |
| PR-AUC（AP） | 0.7805 | 不依赖单个分类阈值的正类排序表现 |
| ROC-AUC | 0.9388 | 不依赖单个分类阈值的类别区分表现 |

Accuracy 与 Precision 含义不同，不能把 86.15% 写成总体准确率。当前数据中，即使把所有用户都预测为负类，Accuracy 也有 88.78%（807/909），但正类召回率为零。完整模型相对此多数类规则高出 5.17 个百分点；**该差值是整个模型相对简单规则的差值，不是时间间隔带来的提升**。因此讨论模型效果时，应同时报告平衡准确率、PR-AUC、F1 和召回率。当前仍漏掉 46/102 名正类，高总体准确率不能掩盖这一限制。

## 时间间隔可能提供的信息

从现有实现看，帖子情绪表示先经过投影，再输入 ODE–GRU。相邻帖子间隔经过 `log1p` 变换，并使用各训练折的第 99 百分位缩放、裁剪到 [0,1]；首帖及 padding 的间隔为零。ODE 根据归一化间隔传播隐藏状态，GRU 再用当前帖子更新状态，最后通过门控与内容表示融合。因此，即使帖子内容与顺序相同，不同的发帖间隔也可能使模型生成不同的状态表示。这是模型设计所允许的作用机制，是否改善预测仍需实验验证。

对本实验最多 256 条有效帖的序列进行描述性统计，排除首帖人为设定的零间隔，保留真实零间隔，且不对原始间隔裁剪，结果如下。所有间隔单位均为天。

| 统计量 | Control（负类） | Depression（正类） |
| --- | --- | --- |
| 有相邻间隔的用户数 | 807 | 102 |
| 相邻有效帖间隔数 | 143,379 | 19,959 |
| 全部间隔的第 25 百分位 | 0.0023 | 0.0036 |
| 全部间隔的中位数 | 0.0285 | 0.0420 |
| 全部间隔的第 75 百分位 | 0.5658 | 0.8643 |
| 全部间隔的第 95 百分位 | 7.1431 | 12.0212 |
| 先求每位用户的间隔中位数，再求用户间中位数 | 0.0533 | 0.0651 |

这些统计显示，样本中的发帖间隔跨度较大，两类的部分分位数存在差异，为研究不规则时间信息提供了动机。但汇总间隔会让发帖较多的用户贡献更多观测，同一用户的多个间隔也不独立；用户级中位数只能补充描述，不能消除所有混杂因素。这些差异不等于统计显著差异，更不能直接证明加入时间特征会提高分类准确率。

当前的时间间隔分布图、风险轨迹图和 Attention Pooling 图均属于描述性证据。前缀性能曲线改变的是已观察的帖子数量，同时增加了文本内容，不能用它来单独归因时间间隔的作用。早期检出者的中位告警位置为第 5 帖，单位是帖子数，也不能解释为 5 天或时间特征带来的时间收益。

## 如何验证时间间隔的独立增益

下面是后续验证方案，**尚未运行，不属于已完成的实验结果**。

| 对照设置 | 时间输入与保留的结构 | 能回答的问题 |
| --- | --- | --- |
| A：真实间隔 | 当前 EOT，使用训练折归一化的真实间隔 | 完整模型的表现 |
| B：固定间隔 | 保留 ODE、GRU、门控及 Transformer，将非首帖有效间隔替换为该训练折归一化间隔的中位数；首帖和 padding 仍为零 | 真实间隔的变化是否优于等间隔序列建模 |
| C：零间隔 | 所有间隔设为零，保留 GRU、门控及 Transformer；ODE 不再传播状态 | 连续时间传播是否优于仅按帖子顺序更新状态 |

A 与 B 是检验真实不规则间隔信息的主要比较。C 可辅助分析，但它同时关闭 ODE 传播，不能完全区分真实间隔信息与 ODE 动态计算的贡献。

各设置应从头训练，沿用相同的用户级训练/验证/测试划分、帖子表示、截断长度、种子 42/43/44、优化器、训练预算和早停规则。各设置按同一规则在自己的验证预测上选择阈值，然后锁定用于测试；不能根据测试表现调阈值，也不宜直接沿用完整模型的阈值而忽略概率尺度变化。仅在已训练模型的测试输入中把间隔清零或打乱，只能作为输入敏感性检查，不能替代重新训练的消融对照。

报告 `ΔAccuracy = Accuracy(A) − Accuracy(B)`，并同时比较 ΔPR-AUC、ΔBalanced Accuracy、ΔF1 和 ΔRecall。对相同 OOF 用户的两组预测进行配对用户 bootstrap，计算指标差值的 95% 区间；同一次重采样必须对两组使用相同用户索引。还应保留同折同种子的差值，展示训练和划分波动。配对 bootstrap 区间以这些已训练模型为条件，不能覆盖重新训练的全部不确定性，也不能通过比较两个单独模型的置信区间是否重叠来替代差值分析。

由于现有测试结果已经被查看，后续对照应预先固定方案并单独记录实验版本。同划分比较应标为事后补充分析；若据此继续选择模型或调参，最终结论需要独立测试数据或新的预先约定评估协议支持。只有在对照中观察到稳定的正向差值，才可报告时间间隔在该数据和协议下带来增益；差值区间跨零时，应写为证据不足。

## 可用于论文的结果讨论

本实验中，融合真实发帖时间间隔的 Emotion–ODE–Transformer 在 909 名用户的五折 OOF 评估中取得 93.95% 的总体准确率、76.89% 的平衡准确率和 0.7805 的 PR-AUC。模型的正类精确率为 86.15%，但召回率为 54.90%，说明当前阈值下仍存在较多漏报。时间间隔能够使模型在两次发帖之间按不同持续时间传播隐藏状态，从而提供帖子顺序之外的时间信息。然而，当前结果来自包含文本、情绪表示、时间编码和序列建模的完整系统，尚缺少固定间隔或无时间传播的对照实验，因此不能将现有分类表现直接归因于时间间隔，也无法据此断言其提高了准确率。时间信息的独立增益仍需在相同划分和训练条件下，通过重新训练的消融实验及配对指标差值分析加以验证。

## 数据与计算来源

- 主指标：`outputs/metrics/oof_metrics.json`、`outputs/tables/classification.csv`；早期检测：`outputs/tables/early_detection.csv`。
- 人数和 Accuracy：`outputs/predictions/oof_final_predictions.parquet`，按 `probability >= threshold` 计算预测，并与 `final_prediction` 核对。
- 间隔统计：`data/processed/post_index.parquet`，使用 `sequence_index > 0` 的 `delta_days`，按 `label` 分组；用户级统计先按 `user_id` 求中位数。
- 模型机制与时间预处理：`src/eot/model.py`、`src/eot/time_features.py`、`configs/eot_main.yaml`。
